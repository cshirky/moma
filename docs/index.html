Chronology

Put MoMA’s paintings in the order they were made

Five stages. Each one harder.

You’ll be shown paintings currently hanging at MoMA, in the wrong order. Drag them so the most recent is on top and the oldest is on the bottom. Click any painting to see it bigger.

You never need to know the year — only which painting came before which. As the stages go on you’ll get more paintings, and the years between them get closer together.
